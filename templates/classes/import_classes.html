批量导入班级与教师绑定

上传包含班级和教师绑定关系的 Excel 或 CSV 文件，系统将自动建立层级架构与绑定管理权。

下载标准导入模板

为避免发生格式解析错误，请下载并使用下方提供的标准导入模板。

下载 Excel (.xlsx) 模板 下载 CSV (.csv) 模板
支持的格式：Excel 电子表格 (.xlsx / .xls) 或 UTF-8 编码的逗号分隔值文件 (.csv)
导入规则与字段说明：
  • 班级名称 (必填)：班级唯一标识，若班级已存在将更新其关联属性，不存在则将新建。
  • 学校 / 学院 / 专业 / 年级 (选填)：有助于构建分层级筛选，留空时系统默认设定为“酷森思大学”、“计算机学院”、“计算机相关专业”、“2024”。
  • 教师工号 (选填)：如提供工号，系统会自动检索该账号并建立班级与该教师的绑定管理关系。如果工号对应的账号尚未注册，绑定关系将在其注册后生效。
